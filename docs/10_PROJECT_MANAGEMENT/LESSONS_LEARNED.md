# Lessons Learned

-   Schematic correctness and physical correctness are different.
-   Footprints must match the purchased parts.
-   ERC/DRC verifies configured rules, not system function.
-   Power should be validated before sensors.
-   A sensor abstraction layer makes software simulation useful.
-   WebView can rapidly package an existing web interface into Android.
-   Biological interpretation must precede sensor selection.
-   Measurements, inferred risks and diagnoses must remain clearly
    separated.
