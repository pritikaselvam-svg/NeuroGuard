# Objectives

## Primary

1.  Design a compact wearable electronics architecture.
2.  Integrate MAX30102 and MPU6050 with an ESP32-C3.
3.  Provide haptic feedback.
4.  Monitor battery voltage.
5.  Develop a caregiver-facing application.
6.  Build a simulated-data pipeline for software validation.
7.  Document the complete engineering process.

## Secondary

-   Keep the architecture low-cost and modular.
-   Minimize wearable volume.
-   Separate sensor drivers from decision logic.
-   Make simulation replaceable by live BLE data.

## Explicit non-objectives

-   Alzheimer's diagnosis.
-   Infection diagnosis.
-   Clinical treatment decisions.
-   Claims of clinical accuracy without validation.
