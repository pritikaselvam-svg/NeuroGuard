# Project Scope and Limitations

## In scope

-   Biological/behavioral signal mapping.
-   Sensor selection.
-   Electronics and PCB.
-   Embedded architecture.
-   Haptic feedback.
-   Battery monitoring.
-   Caregiver software.
-   Simulated-data validation.
-   Wearable CAD.

## Current limitations

1.  The app currently uses simulated data.
2.  Real BLE communication is not yet validated.
3.  Physical sensor accuracy has not been established.
4.  Battery life has not been characterized.
5.  No clinical dataset has been used.
6.  No clinical thresholds have been validated.
7.  The current hardware has no temperature sensor.
8.  The enclosure is a prototype concept until physically fabricated.

## Interpretation

A feature is marked **implemented** only when it is actually
demonstrated. A feature marked **planned** must not be presented as a
completed hardware capability.
