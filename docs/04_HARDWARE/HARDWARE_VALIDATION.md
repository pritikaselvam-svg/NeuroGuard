# Hardware Validation

## Bring-up order

1.  Visual inspection.
2.  Continuity/short check.
3.  USB-C input.
4.  TP4056 charging behavior.
5.  Battery voltage.
6.  3.3 V regulator.
7.  ESP32-C3 boot.
8.  I2C scan.
9.  MAX30102.
10. MPU6050.
11. Motor.
12. Battery ADC.
13. LED.
14. Integrated firmware.

For every test record date, instrument, condition, expected result,
measured result and pass/fail.
