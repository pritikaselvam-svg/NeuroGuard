# Fabrication Notes

## Manufacturing package

-   Gerbers.
-   Drill files.
-   Board outline.
-   BOM.
-   Assembly drawing.
-   Pick-and-place data if required.

## Before ordering

Verify board thickness, copper, clearances, hole sizes, solder mask,
surface finish, component availability and footprints.

## Suggested assembly order

1.  Small passives.
2.  Sensors.
3.  Charger/regulator.
4.  Transistor/diode/LED.
5.  WEMOS C3 Mini.
6.  Connectors.
7.  Battery/motor interfaces.
8.  Inspection.
9.  Power-up.
