# PCB Design Notes

## Subsystems

-   ESP32-C3 module.
-   MAX30102.
-   MPU6050.
-   USB-C charging.
-   TP4056.
-   Li-ion battery.
-   3.3 V regulation.
-   Battery ADC.
-   Haptic driver.
-   Status LED.

## Layout priorities

1.  Compact wearable footprint.
2.  Practical sensor placement.
3.  Short sensitive signal paths.
4.  Local decoupling.
5.  Compact motor-current path.
6.  Accessible charging connection.
7.  Manufacturable clearances.
