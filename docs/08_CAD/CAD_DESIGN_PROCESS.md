# CAD Design Process

## Goal

Create a compact wrist-worn enclosure for the PCB, battery, sensors,
motor and strap.

## Process

``` text
Requirements
→ PCB envelope
→ component packaging
→ outer form
→ sensor contact
→ battery cavity
→ motor clearance
→ back cover
→ strap interface
→ assembly check
```

## Design evidence

Upload actual modelling screenshots showing the progression. Concept
renders should be labelled as concept visuals.

## Key constraints

-   PCB dimensions.
-   Battery thickness.
-   Sensor-to-skin contact.
-   Motor clearance.
-   USB access.
-   Assembly.
-   Strap geometry.
-   Comfort.
