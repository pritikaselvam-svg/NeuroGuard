# Component Packaging

## Packaging concept

``` text
Skin-facing
└── Optical sensor contact region

Main electronics
└── ESP32-C3
└── MAX30102
└── MPU6050
└── Power electronics

Battery cavity
└── Li-ion cell

Haptic/charging
└── Motor
└── USB-C access
```

The final package must be checked against measured components and the
fabricated PCB.
