# Research / Design Gap

## Working gap

NeuroGuard explores the engineering gap between isolated wearable
measurements and a compact caregiver-oriented prototype that combines
motion, optical physiological sensing, haptic alerts, medication support
and software.

## What is not claimed

Fall detection, heart-rate monitoring, activity monitoring and
medication reminders are established technology areas.

## Proposed student contribution

The project demonstrates an integrated, documented pipeline:

``` text
Biological question
→ signal
→ sensor
→ embedded processing
→ event logic
→ caregiver information
```

## What would strengthen the research contribution

-   Systematic literature review.
-   Quantitative benchmark.
-   Controlled test dataset.
-   Sensitivity/specificity or precision/recall.
-   Baseline comparison.
-   Appropriate human-subject methodology.
