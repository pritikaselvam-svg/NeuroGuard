# Literature Matrix Guide

Use `LITERATURE_MATRIX.xlsx` as the working evidence table.

For each source record:

-   Full citation.
-   DOI/URL.
-   Population.
-   Condition.
-   Sensor modality.
-   Signal.
-   Algorithm.
-   Outcome.
-   Validation.
-   Key finding.
-   Limitation.
-   Relevance.

Do not populate a claim from a paper unless the paper has actually been
read and checked.
