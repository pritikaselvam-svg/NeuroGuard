# Evidence Index

Use this directory for visual proof of development.

``` text
research/    literature and biological mapping
schematic/   KiCad schematic
pcb/         placement, routing, DRC, 3D
firmware/    serial logs and sensor tests
app/         dashboard and Android screenshots
cad/         modelling progression
testing/     measured validation
```

Use descriptive names such as `pcb_05_final_3d.png`, not
`final_final.png`.
