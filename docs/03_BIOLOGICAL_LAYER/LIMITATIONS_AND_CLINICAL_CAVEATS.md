# Clinical Caveats and Limitations

1.  NeuroGuard is not a medical device.
2.  No diagnosis is produced.
3.  Heart rate is non-specific.
4.  SpO2 estimates require validation.
5.  Motion-based events can produce false positives/negatives.
6.  Wandering classification requires context and ideally location
    information.
7.  Sleep is currently an activity proxy.
8.  Medication adherence is recorded through a software workflow.
9.  Infection is not detected by the current sensor set.
10. Human testing requires appropriate safety, ethics and consent
    procedures.
