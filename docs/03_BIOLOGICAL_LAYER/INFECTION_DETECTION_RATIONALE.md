# Infection-Related Monitoring Rationale

## Current position

NeuroGuard should **not** be described as an infection detector.

The current hardware has MAX30102 but no dedicated temperature sensor.
Heart-rate elevation is non-specific and may have many causes.

### Preferred wording

Use:

-   "physiological change alert"
-   "possible health deterioration"
-   "elevated heart-rate indicator"

Avoid:

-   "infection detected"
-   "infection diagnosis"
-   "fever detected"

unless a validated temperature sensor is actually integrated and
appropriately evaluated.

## Future extension

A future revision may add skin-contact temperature sensing, but
temperature alone would still not establish infection.
