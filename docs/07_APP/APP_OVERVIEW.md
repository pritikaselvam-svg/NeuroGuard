# Application Overview

The NeuroGuard caregiver app is a mobile-friendly HTML/CSS/JavaScript
interface.

## Main features

-   Patient dashboard.
-   Live-style health metrics.
-   Cognitive-risk visualization.
-   Health-risk visualization.
-   Fall events.
-   Activity/wandering-support events.
-   Sleep/activity trends.
-   Medication management.
-   Alert center.
-   Caregiver information.
-   Device status.

## Demo mode

The app generates simulated values so that the user experience can be
demonstrated before live hardware integration.
